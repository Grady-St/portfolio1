# A5 – Bracket Design

## Objective

The objective is design and analyze a bracket that can safely support a horizontal load between 500 and 800 lbf using a safety factor of 4. Stress analysis will be used to determine the minimum dimensions needed to prevent failure, while stiffness analysis will determine the dimensions required to keep deflection below 0.005 in. The final design will compare both requirements and use the governing dimensions to create detailed multiview drawings.

## Decide

error in the calculated dimensions of Feature A could turn into the later features because the bracket is analyzed sequentially. The dimensions and reactions determined for an earlier feature are used to establish the loading conditions for the next feature. Catching an error in A after completing B, C, D, and E could therefore require those calculations to be repeated.
